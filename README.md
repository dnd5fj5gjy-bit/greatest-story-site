# The Greatest Story Ever Told: site preview

Static site (index.html + assets) with one Vercel serverless route, `api/companion.js`, for the reading companion.

Deploy: import this repo into Vercel, set `ANTHROPIC_API_KEY` in Project Settings > Environment Variables, deploy.
Without the key the companion shows "coming soon" and everything else works. GitHub Pages mirror:
https://dnd5fj5gjy-bit.github.io/greatest-story-site/
